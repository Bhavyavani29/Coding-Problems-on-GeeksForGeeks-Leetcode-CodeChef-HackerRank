## Problem

### Greet

Write a program that takes an input string - the name of a person and prints  **Hello**  and name of the person with a space between them.

### Sample 1:
Input
Output

```
Chef
```

```
Hello Chef
```

### Sample 2:
Input
Output

```
John
```

```
Hello John
```

## Solution

**Language:** Python  
**Runtime:** N/A
