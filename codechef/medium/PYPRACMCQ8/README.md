## Problem

### Counting Black Cells - MCQ

Determine the number of  **black cells**  in an $6 \times 6$ chessboard.

## Solution

**Language:** C++  
**Runtime:** N/A  
**Memory:** N/A  
**Submitted:** 2026-09-04T06:25:46.453Z  

```cpp
n,a,b = map(int,input().split())

# write your code here
print(n - a)
print((n - a) - b)
```
