## Problem

### Prime Check

Rectify the code for below problem.

Given an integer  **N**  less than $10$, determine whether the number  **N**  is prime. If it is prime, print  **prime number** ; otherwise, print  **non-prime number**.

### Sample 1:
Input
Output

```
5
```

```
prime number
```
