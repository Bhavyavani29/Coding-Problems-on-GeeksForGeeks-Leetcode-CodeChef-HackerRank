## Problem

### Positive or Negative

Write a program that takes an integer as input :

- Prints "Positive" if the number is Positive.
- "Negative" if it is negative.
- and "Zero" otherwise.

Check the sample input / output below for further clarity.

### Sample 1:
Input
Output

```
20
```

```
Positive
```
