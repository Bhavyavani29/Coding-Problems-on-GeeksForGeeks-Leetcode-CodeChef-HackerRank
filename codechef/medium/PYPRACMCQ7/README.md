## Problem

### Absolute Difference - MCQ

Given $X$ and $Y$, which of these statements outputs the absolute difference between them?

 **Option 1:** 

```
if (X >= Y):
    print(X - Y)
else:
    print(Y - X)

```

 **Option 2:** 

```
if (X > Y):
    print(X - Y)
else:
    print(Y - X)

```

 **Option 3:** 

```
if (X > Y):
    print(X - Y)
print(Y - X)

```

 **Option 4:** 

```
if (X > Y):
    print(Y - X)
else:
    print(X - Y)

```

## Solution

**Language:** C++  
**Runtime:** N/A  
**Memory:** N/A  
**Submitted:** 2026-09-04T06:28:11.011Z

```cpp
n = int(input())
# write your code here
print((n * n) // 2)
```
