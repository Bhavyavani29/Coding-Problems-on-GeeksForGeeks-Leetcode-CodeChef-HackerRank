## Problem

### Area of circle

Write a program that takes the radius of a circle as input and prints its area

 **formula to calculate area of circle: `3.14 *radius* radius`** 

### Sample 1:
Input
Output

```
5
```

```
78.5
```

## Solution

**Language:** Python  
**Runtime:** N/A  
**Memory:** N/A  
**Submitted:** 2026-08-29T17:11:22.204Z  

```py
# cook your dish here

radius = float(input())
print(3.14 * radius * radius)
```
