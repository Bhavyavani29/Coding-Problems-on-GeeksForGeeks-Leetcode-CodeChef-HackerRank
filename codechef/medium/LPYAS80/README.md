## Problem

### Tuple Reverse

Write a Python program that reverse the given tuple and print its values.

 **Given tuple in code editor:**  (1, 2, 3, 4, 5)
 **Expected Output:**  (5, 4, 3, 2, 1)

## Solution

**Language:** Python  
**Runtime:** N/A  
**Memory:** N/A  
**Submitted:** 2026-09-12T17:46:10.674Z  

```py
# Solution
tup = (1, 2, 3, 4, 5)
print(tup[::-1])

```
